# 🤖 AutoBot - Chatbot de Atendimento de Seguro Auto

## Descrição
Assistente virtual desenvolvido com IA para automatizar o atendimento 
ao segurado, respondendo perguntas frequentes e direcionando solicitações.

## Funcionalidades
- Acionamento de sinistro
- Informações sobre cobertura
- Dúvidas sobre franquia
- Renovação de apólice
- Carro reserva
- Assistência 24h

## Tecnologias utilizadas
- Python 3
- Groq API (LLM: LLaMA 3.3 70B)
- Modelo de linguagem natural para respostas humanizadas

## Como executar
1. Instale a dependência: `pip install groq`
2. Adicione sua chave da API Groq no código
3. Execute: `python chatbot_seguro.py`

## Exemplo de uso
O usuário digita perguntas em linguagem natural e o AutoBot 
responde de forma clara e objetiva sobre seguro auto.# chatbot-seguro-auto
